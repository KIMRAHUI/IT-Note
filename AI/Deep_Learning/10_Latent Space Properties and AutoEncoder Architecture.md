#### 개요

머신러닝의 전체 체계에서 **비지도학습(Unsupervised Learning)** 범주에 속하는 차원 축소(Dimensionality Reduction)의 필요성과 차원의 저주 문제를 다룹니다.   
기존 선형 차원 축소 기법인 **PCA**와 딥러닝 기반 비선형 차원 축소 기법인 오토인코더(AutoEncoder)를 비교하고,   
딥러닝의 핵심 패러다임인 표현 학습(Representation Learning)의 개념, 의미 있는 표현(Meaningful Representation), 고수준 속성 매핑 메커니즘을 전수 정리합니다.

#### 기계학습 분류와 차원 축소 (Dimensionality Reduction)

##### ① 기계학습(Machine Learning)의 전체 체계

| **대분류**                  | **세부 범주**                            | **세부 기법 / 알고리즘 예시**                  |
| ------------------------ | ------------------------------------ | ------------------------------------ |
| **지도학습 (Supervised)**    | **회귀분석 (Regression)**                | 선형 회귀, 릿지/라쏘, 다항 회귀 등                |
|                          | **분류 (Classification)**              | 로지스틱 회귀, SVM, 결정 트리, Random Forest 등 |
| **비지도학습 (Unsupervised)** | **클러스터링 (Clustering)**               | K-Means, DBSCAN, 계층적 군집화 등           |
|                          | **차원 축소 (Dimensionality Reduction)** | **PCA, AutoEncoder, t-SNE, UMAP 등**  |
| **강화학습 (Reinforcement)** | **에이전트 / 정책 학습**                     | Q-Learning, DQN, PPO 등               |

##### 차원 축소의 정의 및 차원의 저주 (Curse of Dimensionality)

| **구 분**         | **상 세 내 용**                                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **차원축소<br> 정의** | 고차원의 입력 데이터($X$)를 정보 손실을 최소화하면서 저차원 공간의 표현 벡터($z$)로 변환하는 알고리즘입니다.                                                        |
| **차원의<br> 저주**  | 데이터의 변수(특징, 차원)가 증가할수록 데이터 공간의 부피가 기하급수적으로 커져 데이터 밀도가 매우 희소(Sparse)해지고, 모델의 성능이 급격히 저하되는 현상입니다.                          |
| **공간투영 원리**     | 3차원 원본 데이터 공간($\text{Gene 1, Gene 2, Gene 3}$) 상의 데이터 포인트를 핵심 변동 축인 주성분축($\text{PC 1, PC 2}$) 평면으로 재투영하여 2차원 공간으로 축소합니다. |


##### 차원 축소 기법 비교: PCA vs AutoEncoder

딥러닝을 활용한 비지도학습($X \rightarrow X'$) 차원 축소 모델과 전통적 통계 기법의 핵심 비교입니다.

| **비교 항목**   | **주성분 분석 (PCA)**          | **오토인코더 (AutoEncoder)**             |
| ----------- | ------------------------- | ----------------------------------- |
| **변환 메커니즘** | **선형(Linear) 직교 변환**      | **신경망 기반 비선형(Non-linear) 변환**       |
| **구조적 특성**  | 데이터의 공분산 행렬을 고유값 분해       | 다층 레이어(Multi-layer) 및 비선형 활성화 함수 결합 |
| **복잡도 표현력** | 선형적 상관관계만 포착 가능           | 복잡하고 곡면화된 고차원 manifold 데이터 표현 가능    |
| **연산 및 해석** | 계산 속도가 매우 빠르고 수학적 해석이 명확함 | 학습 시간이 소요되며 잠재 공간 해석을 위한 검증 필요      |

#### 표현 학습 (Representation Learning)

##### 표현 학습의 개념

표현 학습이란 사람이 직접 특징을 가공하는 수동 특징 엔지니어링(Feature Engineering)을   
대체하여, **신경망이 원본 데이터(Raw Data)로부터 유용한 특징 표현(Feature Representation)을 자동으로 학습**하는 딥러닝의 핵심 원리입니다.

| **데이터 유형**            | **표현 학습을 수행하는 대표적 신경망 구조**                                   |
| --------------------- | ------------------------------------------------------------ |
| **이미지 (Image)**       | CNN (Convolutional Neural Network), Vision Transformer (ViT) |
| **텍스트 / 시퀀스**         | RNN, LSTM, Transformer (BERT, GPT 등)                         |
| **그래프 (Graph)**       | GNN (Graph Neural Network)                                   |
| **범용 / 비지도**          | AutoEncoder, VAE (Variational AutoEncoder)                   |
| **멀티모달 (Multimodal)** | CLIP, Flamingo 등                                             |

##### ② 압축(Compression) vs 의미 있는 표현 (Meaningful Representation)

오토인코더는 고차원 입력 $x$(예: 784차원)를 좁은 병목 구간(Bottleneck)인 저차원 $z$(예: 32차원)로 통과시킨 후 원본 $x'$로 복원해야 합니다. 정보 손실이 강제된 상황에서 복원 오차를 줄여야 하므로, 인코더는 데이터의 본질적 변동 요인을 추출하게 됩니다.

| **구 분**                                  | **정의 및 메커니즘**                                             | **실제 적용 예시**                                   |
| ---------------------------------------- | --------------------------------------------------------- | ---------------------------------------------- |
| **단순 압축 (Compression)**                  | 단순히 정보량의 전체 크기만 줄이는 행위                                    | 무작위 픽셀 일부를 삭제하거나 파일 크기를 줄임                     |
| **의미 있는 표현 (Meaningful Representation)** | 정보량을 줄이되 원본 복원이 가능하도록 **핵심 잠재 요인(Latent Factors)**만 남기는 것 | MNIST 손글씨의 기울기, 선 두께, 숫자 굵기, 폰트 형태 등 핵심 속성만 추출 |

> [!NOTE] 잠재 표현 (Latent Representation)의 재사용성 병목 구간에서 추출된 의미 있는 잠재 벡터 $z$는 단순 원본 복원뿐만 아니라, 분류(Classification), 클러스터링(Clustering), 이상 탐지(Anomaly Detection) 등 다양한 다운스트림(Downstream) 작업의 특징 입력값으로 재사용됩니다.

#### 표현 학습의 직관적 설명 (유재석 프로필 비유)

고차원 픽셀 데이터와 저차원 고수준 속성 표현 간의 차이를 직관적으로 비교한 사례입니다.

##### 픽셀 중심 고차원 데이터 vs 특징 중심 저차원 설명

- **고차원 픽셀 데이터:** $540 \times 720 \times 3 \approx 1,166,400$개의 단순 RGB 수치 나열 (해석 불가능).
    
- **저차원 고수준 표현:** 안경 착용 여부, 미소, 머리 스타일 등 20가지 핵심 속성 벡터만으로 원본 이미지를 유의미하게 추상화하고 재구성할 수 있음.

| **번호** | **고수준 세부 속성 표현 항목**                        |
| ------ | ------------------------------------------ |
| **1**  | 짙은 색 계열(검정에 가까운 다크 브라운)의 단정한 단발 머리 스타일     |
| **2**  | 앞머리가 자연스럽게 옆으로 내려와 이마를 적당히 가림              |
| **3**  | 사각 프레임의 블랙 안경 착용                           |
| **4**  | 얇고 균형 잡힌 얼굴형 - 턱선이 날렵함                     |
| **5**  | 피부 톤은 밝은 쿨톤 계열로 보임                         |
| **6**  | 잔잔하게 미소 짓고 있어 친근한 인상                       |
| **7**  | 눈두덩이 위로 둥근 눈썹이 자연스럽게 정리됨                   |
| **8**  | 짙은 색의 니트 스웨터(푸른 빛이 감도는 딥 그린) 착용            |
| **9**  | 스웨터는 라운드넥 디자인, 어깨 라인이 레글런 형태               |
| **10** | 팔짱을 끼고 있는 안정적인 자세                          |
| **11** | 왼손(사진 기준 오른쪽)에 스마트워치 착용 - 원형 다이얼, 네이비 스트랩  |
| **12** | 시계 디스플레이가 꺼져 있어 블랙 글래스가 통일감 있게 보임          |
| **13** | 손목과 손가락이 가늘고 길게 뻗어 있음                      |
| **14** | 체형은 전체적으로 슬림하고 길쭉한 실루엣                     |
| **15** | 어깨선이 비교적 좁고 경사가 완만함                        |
| **16** | 사진 조명이 균일해 얼굴·옷감에 그림자가 거의 없음               |
| **17** | 배경은 단색의 무채색(짙은 회색)으로 인물을 부각                |
| **18** | 전신이 아닌 허리 위(바스트업) 구도로 촬영                   |
| **19** | 카메라를 정면으로 바라보며 시선이 안정적                     |
| **20** | 전반적으로 깔끔하고 단정한 캐주얼 스타일, 전문직·방송인 같은 세련된 분위기 |

#### 표현 학습의 매핑 메커니즘

인공신경망은 복잡한 고차원 표본 공간을 직접 확률 모델링하지 않고, 저차원의 잠재 공간(Latent Space)을 구축하여 학습 데이터의 각 샘플을 잠재 공간의 포인트로 매핑합니다.

$$\text{학습 데이터 } (X) \xrightarrow{\text{인코더}} \text{잠재 공간 } (z) \xrightarrow{\text{디코더 함수 } f} \text{원본 데이터 공간 재투영 } (X')$$

- **핵심 과제:** 입력 데이터의 변동을 일으키는 독립적인 잠재 변수(Factors of Variation)를 <br> 스스로 찾아내고, 잠재 공간의 한 포인트와 원본 데이터 도메인을 매핑하는 복원 함수 $f$를 학습하는 것입니다.
