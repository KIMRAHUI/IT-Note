
## 저장소 목적

* **기록 모으기**: 흩어져 있는 내 공부 기록과 자료들을 한곳에 모으는 공간입니다.
* **이해하기 쉬운 정리**: 어려운 내용은 최대한 쉽게 풀어서 정리합니다.
* **개념 중심**: 단순한 코드 복사보다는 왜 이런 코드를 쓰는지 개념과 주석 위주로 남깁니다.
* **지속적 수정**: 부족한 부분은 언제든 수정하고 업데이트합니다.

---

## 커밋 메시지 규칙

| 태그 | 설명 |
| --- | --- |
| **Feat** | 새로운 기능 추가 |
| **Fix** | 버그 수정 |
| **Design** | UI 디자인 변경 |
| **BREAKING CHANGE** | 대규모 API 변경 |
| **HOTFIX** | 긴급 치명적 버그 수정 |
| **Style** | 코드 포맷팅, 세미콜론 누락 등 |
| **Refactor** | 코드 리팩토링 |
| **Comment** | 주석 추가 및 변경 |
| **Docs** | 문서 수정 |
| **Test** | 테스트 코드 추가 및 리팩토링 |
| **Chore** | 빌드 태스크, 패키지 매니저 설정 |
| **Rename** | 파일 또는 폴더명 수정 및 이동 |
| **Remove** | 파일 삭제 |
